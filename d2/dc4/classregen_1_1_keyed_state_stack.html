Detailed Description

template<typename T>
class regen::KeyedStateStack< T >

A stack of states that can be applied to a rendering context.

The values are passed together with a key to the apply function. This is useful for OpenGL state changes that require a key to identify the state.

Template Parameters
Tthe type of the state value.
