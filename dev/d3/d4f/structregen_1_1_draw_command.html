Detailed Description

This is used to unify the following two structures: struct IndirectIndexedData { uint32_t count; // index count uint32_t instanceCount; uint32_t firstIndex; int baseVertex; uint32_t baseInstance; }; struct IndirectArrayData { uint32_t count; // vertex count uint32_t instanceCount; uint32_t firstVertex; uint32_t baseInstance; };
