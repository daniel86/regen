Detailed Description

A container for GL data stored in UBOs and TBOs.

This class provides a high-level interface for managing per-object (read-only) data for rasterization. Individual ShaderInput objects can be added, and based on their size and type, the class will automatically populate UBOs and TBOs as needed such that no size constraints are violated. UBO is used as long as there are no individual inputs exceeding maximum UBO size. If the maximum UBO size is exceeded, a TBO is used. This is transparent for shader code, as in case of TBO some defines are added such that the shader code is generated to use TBOs instead of UBOs.
