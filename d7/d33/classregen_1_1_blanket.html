Detailed Description

A blanket mesh.

This class is used to create a blanket mesh. The blankets are created as rectangles with a specified size and texture coordinates. The blankets can be used to create effects such as dust, footprints, or other effects that require quads.

The blankets are initially dead, i.e., they are not rendered. They can be revived by calling reviveBlanket(), which returns the index of the revived blanket instance. The lifetime of the blanket is then reset and it will be rendered until its lifetime expires.
