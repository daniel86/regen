Detailed Description

template<typename T>
struct regen::AlignedArray< T >

A dynamically resizable array with 32-byte alignment. This class provides a simple array-like interface with 32-byte alignment for SIMD operations. It is designed to be used with types that require such alignment, like SIMD registers.
