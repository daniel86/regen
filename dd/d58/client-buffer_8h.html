class  regen::ClientBuffer
 A client buffer that can be used to store data on the client side. This class is used to manage client-side data for shader inputs. It supports double-buffering and provides thread-safe methods for mapping and unmapping data for reading and writing. Reading will never block, but only one thread can write to the data at a time.
