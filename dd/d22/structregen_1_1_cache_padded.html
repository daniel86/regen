Detailed Description

template<typename PrimitiveType>
struct regen::CachePadded< PrimitiveType >

A structure representing a cache line aligned primitive type. This is used to ensure that the primitive type is aligned to a cache line boundary, which can improve performance when accessing the data from multiple threads. It is also padded to ensure that it occupies a full cache line (64 bytes). NOTE: This is specifically useful for atomic types to avoid false sharing.
