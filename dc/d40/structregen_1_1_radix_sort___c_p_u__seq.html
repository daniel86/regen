template<typename IndexType, typename KeyType, int BITS_PER_PASS, int KEY_BITS_EFFECTIVE>
struct regen::RadixSort_CPU_seq< IndexType, KeyType, BITS_PER_PASS, KEY_BITS_EFFECTIVE >

CPU-based Radix Sort implementation This is a sequential implementation of the Radix Sort algorithm, running in a single thread on the CPU. However, this is still significantly faster compared to standard sorting algorithms like std::sort when sorting large.
