const ref_ptr< ShaderInput1f > & TesselationState::lodFactor ( ) const

Tesselation has a range for its levels, maxLevel is currently 64.0. If you set the factor to 0.5 the range will be clamped to [1,maxLevel*0.5] If you set the factor to 32.0 the range will be clamped to [32,maxLevel].

Returns
the LoD factor.
