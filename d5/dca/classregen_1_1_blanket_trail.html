Detailed Description

A trail of blankets.

This class is used to create a trail of blankets. The blankets are created at a specified frequency and are used to create effects such as dust trails, footprints, or other effects that require a series of quads following a path. Note you still need to insert the blankets along the path manually, e.g., based on the movement of a NPC.

The trail mesh mimics the ground mesh, i.e., it uses the same shader except that it inserts additional shader defines to alter the rendering.
