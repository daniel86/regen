Detailed Description

template<typename T, std::size_t Alignment>
class regen::AlignedAllocator< T, Alignment >

A custom allocator that provides aligned memory allocation. This allocator uses posix_memalign to allocate memory with a specified alignment. It is designed to be used with types that require specific alignment, such as SIMD types.

Template Parameters
TThe type of elements in the array.
AlignmentThe alignment in bytes (must be a power of two).
