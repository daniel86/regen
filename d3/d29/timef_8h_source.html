36 // TimeF manages an osg::Timer and features an interface for floating time
37 // in the closed interval [0;1] representing a full day and standard c
38 // time (time_t) simultaneously. The time updates have to be requested
39 // explicitly, thus simplifying usage between multiple recipients.
40 // The time starts cycling automatically, but can also be paused, stopped,
41 // or set to a specific value.
