Detailed Description

template<typename BatchType>
class regen::BatchedBoundingShape< BatchType >

Batched bounding shape.

Template Parameters
BatchTypeThe type of the batch data Batched shape data is drawn from a shared global buffer, and each shape instance has an index into that buffer. This allows efficient storage and retrieval of shape data for operations like collision detection and spatial queries. This is not thread-safe, so make sure to create/destroy shapes in a single thread.
