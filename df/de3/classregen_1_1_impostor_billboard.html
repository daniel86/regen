Detailed Description

A billboard mesh that mimics a more complex mesh.

To this end, we render the mesh to albedo, normal and depth textures and then use this information in deferred shading pipeline. The mesh can be rendered from different perspectives from which the most favorable one is chosen for rendering in the shader.
