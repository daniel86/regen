Detailed Description

A data structure that maintains a list of contiguous ranges.

Semantics of ranges is not pre-defined, can be e.g. free-lists or dirty-lists. We provide here one very fast way of building the list from contiguous blocks in order, and a bit slower method that inserts elements at arbitrary positions in the list. Insert operation attempts to merge inserted range with existing ranges in case they coincide.
